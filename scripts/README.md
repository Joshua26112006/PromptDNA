# scripts/

Developer helper scripts.

| Script       | Purpose                                                        |
| ------------ | ------------------------------------------------------------- |
| `dev.sh`     | Start backend (uvicorn) and frontend (next dev) together (bash). |
| `dev.ps1`    | Same, for Windows PowerShell.                                 |

These are convenience wrappers only; see `backend/README.md` and
`frontend/README.md` for the underlying commands.
