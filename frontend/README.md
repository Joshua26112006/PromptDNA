# PromptDNA — Frontend

Next.js (App Router) + React + Tailwind CSS. Phase 0: development shell only.

## Requirements

- Node.js 20+ (developed on Node 24)

## Setup

```bash
npm install
cp .env.example .env.local   # optional; adjust NEXT_PUBLIC_API_BASE_URL
```

## Run

```bash
npm run dev      # http://localhost:3000
npm run build    # production build
npm run start    # serve the production build
npm run lint     # eslint
```

## Notes

- `AGENTS.md` / `CLAUDE.md` are guidance files generated by `create-next-app`
  for this (breaking-change) Next.js major. Keep them for reference.
- No dashboard, routing, or data fetching is implemented yet — see
  `../docs/` for the approved architecture.
